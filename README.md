# 随机图床插件

## 项目介绍

随机图床插件是一个为 AstrBot 设计的插件，用于从随机图床 API 获取图片和视频，并通过 AstrBot 发送到 QQ 群或好友。

## 功能特性

- 🎲 随机获取图片和视频
- 📤 直接通过 AstrBot 发送媒体
- 🌐 支持多种消息平台
- 🤖 支持 LLM 调用
- 💾 配置持久化存储
- ⏱️ 超时和重试机制
- 📝 详细的错误处理和日志记录

## 安装方法

1. 将插件目录复制到 AstrBot 的 `data/plugins/` 目录
2. 运行 `pip install -r requirements.txt` 安装依赖
3. 重启 AstrBot

## 配置说明

在 AstrBot 的插件管理界面中设置以下参数：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `apiUrl` | 字符串 | `https://example.com` | 随机图床 API 地址 |
| `timeout` | 整数 | `10` | API 请求超时时间（秒） |
| `retryCount` | 整数 | `3` | API 请求重试次数 |

## 使用方法

### 命令方式

在 QQ 群或私聊中发送以下命令：

```
/随机图
```

支持的命令别名：
- `/suijitu`
- `/random`
- `/随机图片`
- `/randomimg`

### LLM 调用

LLM 可以通过 `sendRandomMedia` 工具调用插件功能。

## 工作原理

1. 插件从配置的随机图床 API 获取媒体 URL
2. 检测媒体类型（图片或视频）
3. 使用 AstrBot 的消息发送 API 发送媒体
4. 记录详细的操作日志

## 常见问题

### 1. 提示"获取随机媒体失败"
- 检查网络连接是否正常
- 检查 API 地址是否正确
- 检查 API 地址是否可访问

### 2. 请求超时
- 可以在配置中增加超时时间
- 检查网络连接是否稳定

### 3. 媒体发送失败
- 检查媒体 URL 是否有效
- 检查媒体文件大小是否超过限制
